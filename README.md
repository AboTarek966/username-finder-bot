# 🔎 بوت البحث عن يوزرات غير محجوزة (تيكتوك + انستا)

بوت تيليجرام يفحص إذا كان يوزر معين **غير محجوز** على TikTok و Instagram،
ويقدر يولّد يوزرات جديدة ويجيب غير المحجوز منها.

---

## المتطلبات

- **Node.js 18+** (النسخة الحالية: v24)
- متصفح **Chrome** أو **Edge** مثبّت على الجهاز (البوت يستخدمه في الخلفية للفحص) —
  ويندوز ويندوز11 Edge مثبّت أصلًا.
- توكن بوت من **@BotFather** في تيليجرام.

## خطوات التشغيل

```bash
#1) تثبيت المكتبات
npm install

#2) إنشاء ملف .env ووضع التوكن جواه
copy .env.example .env
#   افتح .env وحط التوكن:  TELEGRAM_BOT_TOKEN=123456:ABC...

#3) تشغيل البوت
npm start

# أو (الأفضل): تشغيل دائم تحت pm2 — شوف قسم "تشغيل 24/7"
pm2 start ecosystem.config.cjs
```

## تشغيل24/7 بدون ما تفتح جهازك 🌐

### الطريقة1: مجاني بالكامل وبدون بطاقة 💚 (GitHub Actions)

بيشتغل على سيرفرات جيتهاب نفسها. **مجانًا وبدون بطاقة ائتمان نهائيًا**،
ومعاه متصفح Chrome و7 جيجا رام — يعني الفحص بيشتغل بنفس الدقة.

> **الحقيقة الوحشة ببساطة:** مفيش "سيرفر مجاني للأبد بدون بطاقة" أصلًا —
> كل اللي بيعرض كده إما تجربة30 يوم (Kamatera وغيره) أو بيبقى فيه بطاقة
> (Oracle/AWS). الطريقة دي هي الاستثناء الحقيقي.

**الخطوات (مرة واحدة، بالواجهة بتاعته — محتاج بس حساب GitHub):**

1. اعمل ريبو جديد وحطه **Public** (العامة = دقائق مجانية غير محدودة)
2. ارفع الملفات: استخدم **الزيب الجاهز** `username-finder-bot-deploy.zip`
   (في نفس المجلد) — افتحه واسحب مجلد `username-finder-bot` جوه الريبو
   من صفحة الريبو على جيتهاب (Upload files)
3. **Settings → Secrets and variables → Actions → New secret**
   - الاسم: `TELEGRAM_BOT_TOKEN`
   - القيمة: التوكن بتاعك من @BotFather
4. **Actions → Run bot → Run workflow** → دوس Start

ومن ساعتها: جيتهاب يشغّل البوت على طول، ولو وقع أو خلص6 ساعات بيرجّعه
تلقائيًا (الفجوة دقيقة تقريبًا كل6 ساعات).

**ملاحظات:**
- الكود هيبقى **عام** — التوكن محفوظ في Secrets مش في الكود، فمش خطر.
- جيتهاب بيوقّف الـ cron تلقائيًا لو الريبو مفيهوش نشاط60 يوم — الحل
  مدمج: البوت بيرجّع يعمل commit صغير كل مرة، فالمشروع فاضل نشِط.

### الطريقة2: سيرفر خاص (لو غيّرت رأيك) 💳

أسرع وأثبت حل، بس بيدفع فلوس (~4-6$/شهر):

#### أ) Docker (الأسهل)

على أي سيرفر فيه Docker:

```bash
scp -r username-finder-bot/ user@SERVER:~
ssh user@SERVER
cd username-finder-bot
docker compose up -d --build
```

`restart: unless-stopped` في `docker-compose.yml` بيرجّع البوت تلقائيًا مع
أي إطفاء للسيرفر، و`pm2` جوه الحاوية بيرجّعه لو وقع.

#### ب) سيرفر عادي (بدون Docker)

```bash
scp -r username-finder-bot/ user@SERVER:~
ssh user@SERVER
cd username-finder-bot && bash scripts/setup-ubuntu.sh
```

السكربت بيثبّت Node + Chrome + pm2 ويسيب البوت شغال ويحفظه يرجع مع الإقلاع.

## تشغيل مؤقت على جهازك (للتجربة بس) 🖥️

مفيش حاجة اتثبت على جهازك — كل حاجة اتنضفت (pm2 + سكربت الإقلاع اتشالوا).
لو حبيت تجرّب محليًا:

```bash
npm start        # شغّل البوت — وإقفله بـ Ctrl+C
```

**أوامر pm2 مفيدة (على السيرفر):**

```bash
pm2 status                    # حالة البوت (online أو لأ)
pm2 logs username-finder      # متابعة اللوج الحي
pm2 restart username-finder   # إعادة تشغيل يدوية
pm2 stop username-finder      # إيقاف مؤقت
```

**ملفات مهمة للسيرفر:**
- `ecosystem.config.cjs` — إعدادات pm2 (المراقبة على `src/` = تحديث تلقائي)
- `Dockerfile` + `docker-compose.yml` — تشغيل الحاوية على أي سيرفر
- `scripts/setup-ubuntu.sh` — تجهيز سيرفر عادي (Node + Chrome + pm2)

## أزرار القائمة (بدون كتابة أوامر)

بعد `/start` بتظهر قائمة أزرار تحت الشات:

| الزر | الوظيفة |
| --- | --- |
| 🔍 **فحص يوزر** | بيسألك الأسماء وتكتبها وهو يفحصها |
| 🎲 **توليد يوزر** | **كل نوع بيشتغل وضع مستمر** — تدوس النوع (عادي/مميز/ثلاثي/رباعي/شبه ثلاثي/شبه رباعي) **وبيبدا يضخ أسماء بسرعه للرسالة** لحد ما تدوس ⏹ **إيقاف** اللي بيظهر تحتها |
| 🔬 **بحث عميق** | يفحص دفعة كبيرة ويعرض المتاح **المؤكد بس** (فحصين لكل اسم) |
| 🧩 **صيغ بديلة** | بيسألك الاسم الأساسي ويجرب الصيغ حواليه، ولو مافيش يوسع بتركيبات حول الكلمة |
| ⚙️ **المنصة** | تيكتوك بس / انستا بس / الاتنين |
| 🔁 **كل الأنواع = مستمر** | تدوس أي نوع (عادي/مميز/ثلاثي/رباعي/شبه ثلاثي/شبه رباعي) **وبيبدا يضخ أسماء بسرعه للرسالة** لحد ما تدوس ⏹ **إيقاف** تحتها |
| ❓ **مساعدة** | عرض المساعدة |

**أنواع التوليد (الأرباعي/الثلاثي = عدد الأحرف):**

| النوع | الطول | مثال |
| --- | --- | --- |
| 🎲 **عادي** | طويل | `orbit26`, `flame_orbit` |
| 💎 **مميز** | 5-6 أحرف حروف+أرقام | `zx.99`, `kz.zk`, `0xkq7`, `vv.88` |
| 🔹 **ثلاثي** | **3 أحرف بالظبط** | `kr1`, `a.b`, `zx9` |
| 🔹 **رباعي** | **4 أحرف بالظبط** | `rh23`, `zx42`, `kr.x` |
| ✨ **شبه ثلاثي** | 4-5 أحرف | `kr.1`, `ab12`, `z.x9` |
| 🔸 **شبه رباعي** | 5-6 أحرف | `rh234`, `ab.xy`, `kr.12` |

> ⚠️ **حقيقة لازم تعرفها:** اليوزرات القصيرة جدًا (3-4 أحرف) على تيك توك
> **محجوزة فعليًا بالكامل** (ملايين المستخدمين قبلك)، والمنصة كمان **بتحفظ**
> أسامي من غير ما بروفايلها يبان. فرصك الحقيقية في **5-6 أحرف** (شبه رباعي)
> وفوق، وده اختبار حقيقي: 8 يوزرات شبه رباعي طلعت منهم **4 متاحة فعلاً**.

وفيها أزرار تحديد العدد:6 /10 /16 يوزر.

**التوليد فوري — من المخزون:** البوت **بيدوّر في الخلفية وهو ساكت** ويبني
"مخزون" من ~16 يوزر متاح لكل نوع (كلهم متأكد بفحصين). لما تدوس 🎲 بياخد
من المخزون **ويرد عليك في أقل من ثانية**، والباقي اللي لسه مخلص بيتمضاف
لنفس الرسالة بتعديل (من غير ما يرن تاني). **مافيش ردّ فيه "مفيش"** — ولو
المخزون فاضي (أول تشغيل) بيستنى **لحد20–30 ثانية** لحد ما يوصله اسم حقيقي
ويردّ بيه، وكمان **بيأكد الأسماء الأقدم في الخلفية** ويشيل أي اسم حد
سجّله في معناه قبل ما نسلّمه.

**والنوع قلّ؟** — مش بيتحوّل لنوع تاني أبدًا: البوت **يفتّش النوع نفسه**
ويكمّل في نفس الرسالة أول ما يلاقي. يعني لو طلبت `رباعي` كل يوزر يوصلك
**4 أحرف فعلًا**. أسامي الثلاثي (3 أحرف) محجوزة فعلًا بالكامل تقريبًا —
عشان كده ممكن ياخد وقت، بس **اللي يوصلك هو النوع اللي طلبته** — مافيش
تسمية غلط أبدًا.

**إشارة التسجيل نفسه (مهم):** المنصة ممكن **تحفظ اليوزر من غير ما
بروفايله يبان** — يعني الاسم يظهر فاضي وأنت لما تجرّب تغيير اسمك يرجع
"غير متاح". عشان كده **فحص إنستا لكل "متاح" بيمرّ من خانة "اسم المستخدم"
في صفحة التسجيل نفسها** (نفس اللي بتغيّر بيه اسمك): لو قالت "غير متوفر"
الاسم بيبقى ❌ على طول، فاللي يوصلك بيمرّ من نفس اختبار إصبعك. **تيكتوك
مالهاش خانة كده قبل التسجيل** — فحصها = "مافيش حساب" بس، والبوت بيوضح
لك لو رفض التغيير ده حفظ عندها مش حساب موجود.

**مانع الحظر:** لو منصة بترجّع إجابات مهملة (حظر مؤقت) 5 مرات ورا بعض،
البوت **يقفّها60 ثانية** ويكمل على التانية بدل ما يضيّع كل الفحوصات،
ولو الاتنين مقفولين بيستني بدل ما يحرق الوقت. وكمان **الاسم المحجوز
بيترفض بطلب HTTP سريع (أقل من ثانية)** بدل فتح المتصفح — عشان المخزون
يمتلي بسرعة ويظل المتصفح للأسماء المحتاجة تأكيد.

**🔁 كل الأنواع = وضع مستمر:** من قائمة 🎲 **توليد يوزر** → كل زرار الأنواع (عادي/مميز/ثلاثي/رباعي/شبه ثلاثي/شبه رباعي) **مكتوب عليه (مستمر)** → تدوس أي واحد **وبيبدا يضخ أسماء بسرعه جداً للرسالة نفسها** (بatches كبيرة، polling كل 0.8ث، سقف 200 اسم/نوع) ويكمل لحد ما تضغط **⏹ إيقاف التوليد المستمر** اللي بيظهر تحت الرسالة. مفيش زرار منفصل ولا قائمة فرعية — النوع نفسه *هو* الوضع المستمر.

**المخزون بيتحفظ في `data/inventory.json`** ويتعمله commit مع شاشة
"keep alive" — يعني لما السيرفر يعمل restart (كل6 ساعات) البوت **يرجع
بنفس الأسماء جاهزة** بدل ما يبدأ من الصفر ويخلّيك تستنى.

وبعد ما تخلص أي دفعة توليد/بحث، بيظهرلك أزرار تحت النتيجة:
**🎲 توليد مرة أخرى** (نفس النوع والعدد) • **🔁 نوع توليد تاني** • **🔬 بحث عميق بنفس النوع**.

## 🔬 البحث العميق إزاي بيشتغل

1. **يولّد دفعة كبيرة** (لحد48 يوزر) — حوالين الكلمة اللي تختارها، ولو
   مفيش نتيجة يوسع البحث بأسماء عشوائية تاني (موجة ثانية).
2. **يفحصهم دفعة دفعة** مع تهدئة تتكيف مع الموقع (لو حس بحظر بيبطّأ لوحده
   ويعود للسرعة لما يخف).
3. **يأكّد كل يوزر "متاح" مرتين**: أول فحص عادي، وبعد ثانيتين فحص تاني
   **من غير كاش** على صفحة جديدة. لو الاسم "اتخدر" يترمي من القائمة.
4. يعرضلك **المؤكد بس**، ويقف بدري بعد ما يلاقي الكفاية (6 يوزرات).

> يعني لو شايف ✅ في نتيجة البحث العميق — ده فحصين متتاليين قالوا
> "غير محجوز". ومع ذلك سجّل بسرعة وراجع بـ `/check` قبل ما تفوّت.

**ملاحظة سرعة:** البحث العميق بياخد دقيقتين تقريبًا عشان بيفحص
عدة عشرات من الصفحات. لو الكلمة الأساسية شائعة جدًا (زي `gamer`)
هتلاقي كل الصيغ حوالها محجوزة — جرّب كلمة أقل شيوعًا عشان النتيجة أحسن.

## إزاي بيشتغل الفحص؟

المنصتين مافيش عندهن API رسمي يقول "الاسم ده فاضي"، فالبوت بيعمل الآتي:

1. **تيكتوك — الدليل من تيكتوك نفسها:** الصفحة بتحتوي JSON رسمي
   (`webapp.user-detail`) بتاع البروفايل:
   - `statusCode: 0` وفيه `uniqueId` بنفس الاسم → ❌ محجوز.
   - `statusCode: 10221` ("user not exist") **من غير** userInfo أبدًا → ✅ غير محجوز.
   - الدليل لازم **يتكرر في طلب تاني مستقل** (بعد ~1.3 ثانية) **ويكون حسابنا
     الضابط (`@nasa`) باين بنفس الوقت** — غير كده البوت يرفض ويقول "مش مؤكد".
     كل ده بـHTTP عادي (~2–8 ثواني) من غير متصفح.
2. **متصفح حقيقي (Chrome/Edge بدون واجهة)** كطريق تأكيد/بديل: يفتح صفحة
   البروفايل ويقرأ نفس الـJSON + رسالة "Couldn't find this account" لو الرسم
   ظهر. مفيد جدًا على الشبكات اللي تيكتوك بتردّ عليها بقشرة "Please wait".
3. **انستا:** `og:description` أو `profilePage_` → ❌ محجوز، و"Profile isn't
   available" → ✅ غير محجوز (مع تأكيد بطلب HTTP — عشان مرة اتحصل غلط ✅).
4. **كاش داخلي:** النتيجة بتتخزن6 ساعات (والنتيجة غير المؤكدة دقيقة واحدة فقط).

> ملاحظة عملية اتأكدنا منها على سيرفر GitHub نفسه: الصفحة المرئية هناك **مابتعرضش
> نص أبدًا** (الرسم بيسقط)، واللي بيفصل صح من غلط هو الـJSON الرسمي ده.

## إنستا على السيرفر: ليه بتقول "مش مؤكد"؟

اتأكدنا بتجربة مباشرة على سيرفر GitHub نفسه:

- **تيكتوك:** بتردّ عادي من السيرفر ✅ (فحوصات بطيئة شوية).
- **إنستا:** كل طلب من IP سيرفر بيرجّع
  `https://www.instagram.com/accounts/login/?next=...` — يعني **حائط تسجيل
  دخول**، والبروفايل ما بيوصلش أصلًا (لا محجوز ولا فاضي). عشان كده البوت
  **مش بيكذب**: بيقول "⚠️ مش مؤكد" ومستعد يخفي اسم صح بدل ما يعرض غلط.
- من **جهازك العادي** (عنوان منزل) إنستا شغالة تمام: محجوز في **1–3 ثواني**
  (علامة موجبة: og:description / profilePage_) وفاضي في **~11 ثانية**
  (الصفحة بتظهر "Profile isn't available" + حساب ضابط + تأكيد تاني).

**طريقتين تشغّل إنستا فعليًا:**

1. **كوكيز حسابك — تشتغل 24 ساعة على السيرفر:**
   1. سجّل دخول في إنستا من متصفحك.
   2. اضغط F12 → تبويب Application → Cookies → `https://www.instagram.com`.
   3. انسخ قيمة الكوكي اسمها **`sessionid`**.
   4. GitHub → Settings → Secrets and variables → Actions → **New secret**:
      الاسم `IG_SESSION` والقيمة هي الـsessionid → وبعدها دوس **Run workflow**.
   > ⚠️ استخدم **حساب مسجّل مش حسابك الأساسي**: إنستا ممكن تقيّد أي حساب
   > بيشتغل آليًا (وهو ضد شروطهم). البوت بيشتغل عادي من غيره — إنستا بس
   > تفضل "مش مؤكد" وتيكتوك يكمّل لوحدها.
2. **التشغيل على جهازك:** `npm install && npm start` — إنستا هتشتغل من عنوانك
   مباشرة (مسحح ومطابق لكل الفحوصات).

## ملاحظات وحدود

- ⚠️ الفحص **تقديري**. النتايج المتأكد منها (✅/❌) مبنية على محتوى الصفحة الفعلي،
  بس لازم تتأكد بنفسك قبل ما تحجز اليوزر.
- المنصتين بيحدّوا الطلبات الكتير. لو شفت ⚠️ كتير، استنى دقايق.
- البوت بيفحص **بدون تسجيل دخول** (زي أي زائر)، وده أأمن من ناحية حسابك.
- استخدم البوت بذكاء: مبالغة الفحص ممكن تسبب حظر مؤقت لعنوان IP بتاعك.
