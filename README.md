# 🔎 بوت البحث عن يوزرات غير محجوزة (تيكتوك + إنستا)

بوت تيليجرام يفحص ما إذا كان يوزر معين **غير محجوز** على TikTok و Instagram،
ويولّد يوزرات جديدة ويعرض غير المحجوز منها.

---

## المتطلبات

- **Node.js 18+** (النسخة الحالية: v24)
- متصفح **Chrome** أو **Edge** مثبّت على الجهاز (يستخدمه البوت في الخلفية للفحص) —
  على ويندوز 11 يُثبَّت Edge افتراضيًا.
- توكن بوت من **@BotFather** في تيليجرام.

## خطوات التشغيل

```bash
# 1) تثبيت المكتبات
npm install

# 2) إنشاء ملف .env ووضع التوكن فيه
copy .env.example .env
#   افتح .env وضع التوكن:  TELEGRAM_BOT_TOKEN=123456:ABC...

# 3) تشغيل البوت
npm start

# أو (الأفضل): تشغيل دائم تحت pm2 — انظر قسم «تشغيل 24/7»
pm2 start ecosystem.config.cjs
```

### الطريقة 1: مجانية بالكامل وبدون بطاقة 💚 (GitHub Actions)

تعمل على خوادم GitHub نفسها. **مجانًا وبدون بطاقة ائتمان نهائيًا**،
ومزودة بمتصفح Chrome و 7 جيجابايت من الذاكرة — أي أن الفحص يعمل بنفس الدقة.

> **الحقيقة القاسية ببساطة:** لا يوجد «خادم مجاني للأبد بدون بطاقة» أصلًا —
> كل ما يُعرض بهذا الشكل إما تجربة لمدة 30 يومًا (Kamatera وغيرها) أو يتطلب
> وجود بطاقة (Oracle/AWS). هذه الطريقة هي الاستثناء الحقيقي.

**الخطوات (مرة واحدة، وبواجهة GitHub — تحتاج فقط إلى حساب GitHub):**

1. أنشئ مستودعًا جديدًا وضعه **Public** (العامة = دقائق مجانية غير محدودة)
2. ارفع الملفات: استخدم **الملف المضغوط الجاهز** `username-finder-bot-deploy.zip`
   (في نفس المجلد) — افتحه واسحب مجلد `username-finder-bot` داخل المستودع
   من صفحة المستودع على GitHub (Upload files)
3. **Settings → Secrets and variables → Actions → New secret**
   - الاسم: `TELEGRAM_BOT_TOKEN`
   - القيمة: التوكن الخاص بك من @BotFather
4. **Actions → Run bot → Run workflow** → اضغط Start

ومن بعدها: يشغّل GitHub البوت باستمرار، وإذا تعطل أو انتهت مهلة 6 ساعات
يعيد تشغيله تلقائيًا (مع فجوة تقريبًا دقيقة واحدة كل 6 ساعات).

**ملاحظات:**
- سيبقى الكود **عامًّا** — التوكن محفوظ في Secrets وليس في الكود، فلا خطر.
- يوقف GitHub مهام cron تلقائيًا إذا لم يكن في المستودع نشاط لمدة 60 يومًا —
  والحل مدمج: يعيد البوت إجراء commit صغير في كل مرة، فيبقى المشروع نشطًا.

أسرع حل وأكثر ثباتًا، لكنه يتطلب دفع رسوم (~4-6$ شهريًا):

#### أ) Docker (الأسهل)

على أي خادم عليه Docker:


```bash
scp -r username-finder-bot/ user@SERVER:~
ssh user@SERVER
cd username-finder-bot && bash scripts/setup-ubuntu.sh
```

يثبت السكربت Node + Chrome + pm2 ويترك البوت يعمل ويحفظه ليعود مع الإقلاع.

## تشغيل مؤقت على جهازك (للتجربة فقط) 🖥️

لم يُثبَّت شيء على جهازك — أُزيل كل شيء (pm2 + سكربت الإقلاع).
إن أردت تجربته محليًّا:

```bash
npm start        # شغّل البوت — وأوقفه بـ Ctrl+C
```

**أوامر pm2 مفيدة (على الخادم):**

```bash
pm2 status                    # حالة البوت (online أو لا)
pm2 logs username-finder      # متابعة السجل الحي
pm2 restart username-finder   # إعادة تشغيل يدوية
pm2 stop username-finder      # إيقاف مؤقت
```

**ملفات مهمة للخادم:**
- `ecosystem.config.cjs` — إعدادات pm2 (المراقبة على `src/` = تحديث تلقائي)
- `Dockerfile` + `docker-compose.yml` — تشغيل الحاوية على أي خادم
- `scripts/setup-ubuntu.sh` — تجهيز خادم عادي (Node + Chrome + pm2)

## أزرار القائمة (دون كتابة أوامر)

بعد `/start` تظهر قائمة أزرار تحت المحادثة:

| الزر | الوظيفة |
| --- | --- |
| 🔍 **فحص يوزر** | يطلب الأسماء وتكتبها فيفحصها |
| 🎲 **توليد يوزر** | **كل نوع يعمل وضع الاستمرار** — تضغط على النوع (عادي/مميز/ثلاثي/رباعي/شبه ثلاثي/شبه رباعي) **فيبدأ بضخ أسماء بسرعة إلى الرسالة** حتى تضغط ⏹ **إيقاف** الذي يظهر تحتها |

> لا توجد خيارات لعدد اليوزرات (6/10/16) بعد الآن: التوليد **لا يتوقف من تلقاء نفسه** —
> يستمر حتى يطلب المستخدم الإيقاف بزر ⏹. ويوقف البوت البحث أيضًا عند أي استفسار من المستخدم.

**أنواع التوليد (الرباعي/الثلاثي = عدد الأحرف):**

| النوع | الطول | مثال |
| --- | --- | --- |
| 🎲 **عادي** | طويل | `orbit26`, `flame_orbit` |
| 💎 **مميز** | 5-6 أحرف حروف+أرقام | `zx.99`, `kz.zk`, `0xkq7`, `vv.88` |
| 🔹 **ثلاثي** | **3 أحرف تمامًا** | `kr1`, `a.b`, `zx9` |
| 🔹 **رباعي** | **4 أحرف تمامًا** | `rh23`, `zx42`, `kr.x` |
| ✨ **شبه ثلاثي** | 4-5 أحرف | `kr.1`, `ab12`, `z.x9` |
| 🔸 **شبه رباعي** | 5-6 أحرف | `rh234`, `ab.xy`, `kr.12` |

> ⚠️ **حقيقة يجب أن تعرفها:** اليوزرات القصيرة جدًا (3-4 أحرف) على تيكتوك
> **محجوزة فعليًا بالكامل** (ملايين المستخدمين قبلك)، والمنصة أيضًا **تحتفظ**
> بأسماء دون أن يظهر بروفايلها. فرصك الحقيقية في **5-6 أحرف** (شبه رباعي)
> وما فوق — وهذا اختبار حقيقي: 8 يوزرات شبه رباعي ظهر منها **4 متاحة فعلًا**.

**التوليد فوري — من المخزون:** البوت **يبحث في الخلفية بصمت** ويبني
«مخزون» من ~16 يوزر متاح لكل نوع (كلها مؤكد بفحصين). عند الضغط على 🎲 يأخذ
من المخزون **ويردّ في أقل من ثانية**، وما تبقّى يُضاف إلى الرسالة نفسها
بعديلها (دون أن يرنّ مرة أخرى). **لا يوجد ردّ ينتهي بـ«لا يوجد»** — وحتى
إن كان المخزون فارغًا (أول تشغيل) **ينتظر 20–30 ثانية** حتى يصله اسم حقيقي
ويردّ به، كما **يؤكد الأسماء الأقدم في الخلفية** ويزيل أي اسم سجّله
غيره قبل تسليمه.

**ونفدت الأنواع؟** — لا يتحوّل إلى نوع آخر أبدًا: البوت **يبحث النوع نفسه**
ويكمل في نفس الرسالة فور العثور عليه. أي أن لو طلبت `رباعي` فكل يوزر يصل إليك
**4 أحرف فعلًا**. أسماء الثلاثي (3 أحرف) محجوزة فعلًا بالكامل تقريبًا —
لذلك قد يستغرق الأمر وقتًا، لكن **الذي يصل إليك هو النوع الذي طلبته** —
ولا توجد تسمية خاطئة أبدًا.

**إشارة التسجيل نفسه (مهم):** قد **تحتفظ المنصة باليوزر دون أن يظهر بروفايله** —
أي أن الاسم يظهر فارغًا وعندما تجرّب تغيير اسمك يعود «غير متاح». لذلك
**يمر فحص إنستا لكل «متاح» من خانة «اسم المستخدم» في صفحة التسجيل نفسها**
(التي تغيّر بها اسمك): إذا قالت «غير متوفر» يصبح الاسم ❌ فورًا، فالذي يصل إليك
يمارس نفس اختبارك. **تيكتوك ليس لديها خانة كهذه قبل التسجيل** — فحصها =
«لا يوجد حساب» فقط، ويبين لك البوت إن رفض التغيير فهو احتفاظ لديها لا حساب موجود.

**مانع الحظر:** إذا أعادت منصة إجابات مهملة (حظر مؤقت) 5 مرات متتالية،
**يوقفها 60 ثانية** ويكمل على الأخرى بدل إضاعة كل الفحوصات،
وإذا كان كلاهما مقفلين ينتظر بدل حرق الوقت. كما **الاسم المحجوز
يُرفض بطلب HTTP سريع (أقل من ثانية)** بدل فتح المتصفح — ليمتلأ
المخزون بسرعة ويبقى المتصفح للأسماء التي تحتاج تأكيدًا.

**🔁 كل الأنواع = وضع مستمر:** من قائمة 🎲 **توليد يوزر** → كل أزرار الأنواع (عادي/مميز/ثلاثي/رباعي/شبه ثلاثي/شبه رباعي) **مكتوب عليها (مستمر)** → تضغط على أي واحد **فيبدأ بضخ أسماء بسرعة كبيرة إلى الرسالة نفسها** (دفعات كبيرة، polling كل 0.8 ثانية، سقف 200 اسم/نوع) ويستمر حتى تضغط **⏹ إيقاف التوليد المستمر** الذي يظهر تحت الرسالة. لا توجد أزرار منفصلة ولا قائمة فرعية — النوع نفسه *هو* وضع الاستمرار.

**يُحفظ المخزون في `data/inventory.json`** ويُجرى له commit مع شاشة
«keep alive» — أي أن الخادم عند إعادة التشغيل (كل 6 ساعات) **يعود
بالأسماء نفسها جاهزة** بدل البدء من الصفر وجعلك تنتظر.

وبعد انتهاء أي دفعة توليد/بحث، تظهر أزرار تحت النتيجة:
**🔁 توليد مرة أخرى** (مستمر بنفس النوع) • **🔁 نوع توليد آخر** • **🔬 بحث عميق بنفس النوع**.

## أوامر مكتوبة (اختيارية)

| الأمر | الوظيفة |
| --- | --- |
| `/start` أو `/help` | المساعدة + القائمة |

**الرموز في الرد:** ✅ غير محجوز | ❌ محجوز | ⚠️ غير مؤكد (حظر مؤقت — أعد المحاولة لاحقًا)

```bash

```

## 🔬 كيف يعمل البحث العميق

1. **يولّد دفعة كبيرة** (حتى 48 يوزر) — حول الكلمة التي تختارها، وإذا
   لم توجد نتيجة يوسّع البحث بأسماء عشوائية أخرى (موجة ثانية).
2. **يفحصهم دفعة بدفعة** مع تهدئة تتكيف مع الموقع (إذا استشعر حظرًا يبطئ من تلقاء نفسه
   ويعود للسرعة عندما يخفّ).
3. **يؤكد كل يوزر «متاح» مرتين**: أول فحص عادي، وبعد ثانيتين فحص ثانٍ
   **بدون كاش** على صفحة جديدة. إذا «خُدر» الاسم يُرمى من القائمة.
4. يعرض لك **المؤكد فقط**، ويتوقف مبكرًا بعد إيجاد القدر الكافي (6 يوزرات).

> أي أن رؤية ✅ في نتيجة البحث العميق — تعني فحصين متتاليين قالا
> «غير محجوز». ومع ذلك سجّل بسرعة وراجع بـ `/check` قبل أن تفوته.

**ملاحظة سرعة:** يستغرق البحث العميق دقيقتين تقريبًا لأنه يفحص
عدة عشرات من الصفحات. إذا كانت الكلمة الأساسية شائعة جدًا (مثل `gamer`)
ستجد كل الصيغ حولها محجوزة — جرّب كلمة أقل شيوعًا لتحصل على نتيجة أفضل.

## كيف يعمل الفحص؟

المنصتان ليس لهما API رسمي يقول «الاسم فارغ»، فيقوم البوت بما يلي:

1. **تيكتوك — الدليل من تيكتوك نفسها:** الصفحة تحتوي JSON رسمي
   (`webapp.user-detail`) للبروفايل:
   - `statusCode: 0` ويحتوي `uniqueId` بنفس الاسم → ❌ محجوز.
   - `statusCode: 10221` («user not exist») **بدون** userInfo أبدًا → ✅ غير محجوز.
   - يجب أن **يتكرر الدليل في طلب مستقل ثانٍ** (بعد ~1.3 ثانية) **وأن يكون حسابنا
     الضابط (`@nasa`) ظاهرًا بنفس الوقت** — وإلا يرفض البوت ويقول «غير مؤكد».
     كل هذا عبر HTTP عادي (~2–8 ثوانٍ) دون متصفح.
2. **متصفح حقيقي (Chrome/Edge بدون واجهة)** كطريق تأكيد/بديل: يفتح صفحة
   البروفايل ويقرأ نفس الـJSON + رسالة «Couldn't find this account» إذا ظهرت
   الصفحة. مفيد جدًا على الشبكات التي تردّ عليها تيكتوك بقشرة «Please wait».
3. **إنستا:** `og:description` أو `profilePage_` → ❌ محجوز، و«Profile isn't
   available» → ✅ غير محجوز (مع تأكيد بطلب HTTP — كي لا يظهر ✅ خاطئ مرة).
4. **كاش داخلي:** تُحفظ النتيجة لمدة 6 ساعات (والنتيجة غير المؤكدة دقيقة واحدة فقط).

> ملاحظة عملية تأكّدنا منها على خادم GitHub نفسه: الصفحة المرئية هناك **لا تعرض
> نصًّا أبدًا** (الرسم يسقط)، والفاصل بين الصحيح والخطأ هو الـJSON الرسمي هذا.

## إنستا على الخادم: لماذا تقول «غير مؤكد»؟

تأكدنا بتجربة مباشرة على خادم GitHub نفسه:

- **تيكتوك:** تردّ عاديًا من الخادم ✅ (فحوصات أبطأ قليلاً).
- **إنستا:** كل طلب من IP الخادم يعيد
  `https://www.instagram.com/accounts/login/?next=...` — أي **جدار تسجيل
  دخول**، ولا يصل البروفايل أصلًا (لا محجوز ولا فارغ). لذلك **لا يكذب البوت**:
  يقول «⚠️ غير مؤكد» ومستعد لإخفاء اسم صحيح بدل عرض خطأ.
- من **جهازك العادي** (عنوان منزلي) تعمل إنستا تمامًا: محجوز في **1–3 ثوانٍ**
  (علامة موجبة: og:description / profilePage_) وفارغ في **~11 ثانية**
  (تظهر الصفحة «Profile isn't available» + حساب ضابط + تأكيد ثانٍ).

**طريقتان لتشغيل إنستا فعليًا:**

1. **كوكيز حسابك — تعمل 24 ساعة على الخادم:**
   1. سجّل دخول في إنستا من متصفحك.
   2. اضغط F12 → تبويب Application → Cookies → `https://www.instagram.com`.
   3. انسخ قيمة الكوكي المسمى **`sessionid`**.
   4. GitHub → Settings → Secrets and variables → Actions → **New secret**:
      الاسم `IG_SESSION` والقيمة هي الـsessionid → ثم اضغط **Run workflow**.
   > ⚠️ استخدم **حسابًا مسجّلًا لا حسابك الأساسي**: قد تقيّد إنستا أي حساب
   > يعمل آليًّا (وهذا ضد شروطهم). البوت يعمل عاديًا بدونه — تبقى إنستا فقط
   > «غير مؤكد» وتكمل تيكتوك وحدها.
2. **التشغيل على جهازك:** `npm install && npm start` — ستعمل إنستا من عنوانك
   مباشرة (مصحّح ومطابق لكل الفحوصات).

## ملاحظات وحدود

- ⚠️ الفحص **تقديري**. النتائج المؤكدة منها (✅/❌) مبنية على محتوى الصفحة الفعلي،
  لكن يجب أن تتأكد بنفسك قبل حجز اليوزر.
- المنصتان تحدّان من الطلبات الكثيرة. إذا رأيت ⚠️ كثيرًا، انتظر دقائق.
- البوت يفحص **بدون تسجيل دخول** (كأي زائر)، وهذا أأمن من ناحية حسابك.
- استخدم البوت بذكاء: الإفراط في الفحص قد يسبب حظرًا مؤقتًا لعنوان IP الخاص بك.

## هيكل المشروع

```
src/
  index.js     # أوامر البوت ورسائل تيليجرام
  checker.js   # منطق الفحص (متصفح + بدائل HTTP + كاش)
  browser.js   # إدارة بركة صفحات المتصفح
  generator.js # توليد يوزرات وصيغ بديلة
  hunter.js    # محرك البحث العميق (تأكيد مزدوج)
  cli.js       # أوامر سطر الأوامر للاختبار
ecosystem.config.cjs  # إعدادات pm2 للتشغيل الدائم
```
