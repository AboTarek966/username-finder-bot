# 🔎 بوت البحث عن يوزرات غير محجوزة (تيكتوك + انستا)

بوت تيليجرام يفحص إذا كان يوزر معين **غير محجوز** على TikTok و Instagram،
ويقدر يولّد يوزرات جديدة ويجيب غير المحجوز منها.

---

## المتطلبات

- **Node.js 18+** (النسخة الحالية: v24)
- متصفح **Chrome** أو **Edge** مثبّت على الجهاز (البوت يستخدمه في الخلفية للفحص) —
  ويندوز ويندوز11 Edge مثبّت أصلًا.
- توكن بوت من **@BotFather** في تيليجرام.

## خطوات التشغيل

```bash
#1) تثبيت المكتبات
npm install

#2) إنشاء ملف .env ووضع التوكن جواه
copy .env.example .env
#   افتح .env وحط التوكن:  TELEGRAM_BOT_TOKEN=123456:ABC...

#3) تشغيل البوت
npm start

# أو (الأفضل): تشغيل دائم تحت pm2 — شوف قسم "تشغيل 24/7"
pm2 start ecosystem.config.cjs
```

## تشغيل24/7 بدون ما تفتح جهازك 🌐

لو عايز البوت يفضل شغال **حتى وهو لابتوبي مقفول** — لازم يشتغل في السحابة.
فيه طريقتين:

---

### الطريقة1: مجاني بالكامل وبدون بطاقة 💚 (GitHub Actions)

بيشتغل على سيرفرات جيتهاب نفسها. **مجانًا وبدون بطاقة ائتمان نهائيًا**،
ومعاه متصفح Chrome و7 جيجا رام — يعني الفحص بيشتغل بنفس الدقة.

> **الحقيقة الوحشة ببساطة:** مفيش "سيرفر مجاني للأبد بدون بطاقة" أصلًا —
> كل اللي بيعرض كده إما تجربة30 يوم (Kamatera وغيره) أو بيبقى فيه بطاقة
> (Oracle/AWS). الطريقة دي هي الاستثناء الحقيقي.

**الخطوات (مرة واحدة، بالواجهة بتاعته — محتاج بس حساب GitHub):**

1. اعمل ريبو جديد وحطه **Public** (العامة = دقائق مجانية غير محدودة)
2. ارفع الملفات: استخدم **الزيب الجاهز** `username-finder-bot-deploy.zip`
   (في نفس المجلد) — افتحه واسحب مجلد `username-finder-bot` جوه الريبو
   من صفحة الريبو على جيتهاب (Upload files)
3. **Settings → Secrets and variables → Actions → New secret**
   - الاسم: `TELEGRAM_BOT_TOKEN`
   - القيمة: التوكن بتاعك من @BotFather
4. **Actions → Run bot → Run workflow** → دوس Start

ومن ساعتها: جيتهاب يشغّل البوت على طول، ولو وقع أو خلص6 ساعات بيرجّعه
تلقائيًا (الفجوة دقيقة تقريبًا كل6 ساعات).

**ملاحظات:**
- الكود هيبقى **عام** — التوكن محفوظ في Secrets مش في الكود، فمش خطر.
- جيتهاب بيوقّف الـ cron تلقائيًا لو الريبو مفيهوش نشاط60 يوم — الحل
  مدمج: البوت بيرجّع يعمل commit صغير كل مرة، فالمشروع فاضل نشِط.

---

### الطريقة2: سيرفر خاص (لو غيّرت رأيك) 💳

أسرع وأثبت حل، بس بيدفع فلوس (~4-6$/شهر):

#### أ) Docker (الأسهل)

على أي سيرفر فيه Docker:

```bash
scp -r username-finder-bot/ user@SERVER:~
ssh user@SERVER
cd username-finder-bot
docker compose up -d --build
```

`restart: unless-stopped` في `docker-compose.yml` بيرجّع البوت تلقائيًا مع
أي إطفاء للسيرفر، و`pm2` جوه الحاوية بيرجّعه لو وقع.

#### ب) سيرفر عادي (بدون Docker)

```bash
scp -r username-finder-bot/ user@SERVER:~
ssh user@SERVER
cd username-finder-bot && bash scripts/setup-ubuntu.sh
```

السكربت بيثبّت Node + Chrome + pm2 ويسيب البوت شغال ويحفظه يرجع مع الإقلاع.

> نتايج ⚠️ كإشارة "جرّب بعد شوية" زي ما هو الحال من البيت.

## تشغيل مؤقت على جهازك (للتجربة بس) 🖥️

مفيش حاجة اتثبت على جهازك — كل حاجة اتنضفت (pm2 + سكربت الإقلاع اتشالوا).
لو حبيت تجرّب محليًا:

```bash
npm start        # شغّل البوت — وإقفله بـ Ctrl+C
```

**أوامر pm2 مفيدة (على السيرفر):**

```bash
pm2 status                    # حالة البوت (online أو لأ)
pm2 logs username-finder      # متابعة اللوج الحي
pm2 restart username-finder   # إعادة تشغيل يدوية
pm2 stop username-finder      # إيقاف مؤقت
```

**ملفات مهمة للسيرفر:**
- `ecosystem.config.cjs` — إعدادات pm2 (المراقبة على `src/` = تحديث تلقائي)
- `Dockerfile` + `docker-compose.yml` — تشغيل الحاوية على أي سيرفر
- `scripts/setup-ubuntu.sh` — تجهيز سيرفر عادي (Node + Chrome + pm2)

## أزرار القائمة (بدون كتابة أوامر)

بعد `/start` بتظهر قائمة أزرار تحت الشات:

| الزر | الوظيفة |
| --- | --- |
| 🔍 **فحص يوزر** | بيسألك الأسماء وتكتبها وهو يفحصها |
| 🎲 **توليد يوزر** | يفتح شاشة الأنماط5 + اختيار العدد، **ويدور لحد ما يلاقي** العدد المطلوب، ولو قلّ النوع نفسه **يوسّع تلقائيًا للأنواع المجاورة** ويكتب نوع كل اسم |
| 🔬 **بحث عميق** | يفحص دفعة كبيرة ويعرض المتاح **المؤكد بس** (فحصين لكل اسم) |
| 🧩 **صيغ بديلة** | بيسألك الاسم الأساسي ويجرب الصيغ حواليه، ولو مافيش يوسع بتركيبات حول الكلمة |
| ⚙️ **المنصة** | تيكتوك بس / انستا بس / الاتنين |
| ❓ **مساعدة** | عرض المساعدة |

**أنواع التوليد (الأرباعي/الثلاثي = عدد الأحرف):**

| النوع | الطول | مثال |
| --- | --- | --- |
| 🎲 **عادي** | طويل | `orbit26`, `flame_orbit` |
| 💎 **مميز** | 5-6 أحرف حروف+أرقام | `zx.99`, `kz.zk`, `0xkq7`, `vv.88` |
| 🔹 **ثلاثي** | **3 أحرف بالظبط** | `kr1`, `a.b`, `zx9` |
| 🔹 **رباعي** | **4 أحرف بالظبط** | `rh23`, `zx42`, `kr.x` |
| ✨ **شبه ثلاثي** | 4-5 أحرف | `kr.1`, `ab12`, `z.x9` |
| 🔸 **شبه رباعي** | 5-6 أحرف | `rh234`, `ab.xy`, `kr.12` |

> ⚠️ **حقيقة لازم تعرفها:** اليوزرات القصيرة جدًا (3-4 أحرف) على تيك توك
> **محجوزة فعليًا بالكامل** (ملايين المستخدمين قبلك) — البوت هيقولك ❌ بصدق
> لأنها فعلًا محجوزة. فرصك الحقيقية في **5-6 أحرف** (شبه رباعي) وفوق،
> وده اختبار حقيقي:8 يوزرات شبه رباعي طلعت منهم **4 متاحة فعلاً**.

وفيها أزرار تحديد العدد:6 /10 /16 يوزر.

**التوليد مش بيقف عند أول دفعة:** بيمشي موجة ورا موجة من الأسماء الجديدة
لحد ما يحقق العدد اللي طلبته — أو يوصل لأقصى حد (أكبر عدد `العدد×10+15`
فحص بحد أقصى150، و~10 دقايق كحد زمني صارم عشان ماتستناش للأبد). الأسماء
"المش مؤكدة" بتتجرّب تاني مرة واحدة قبل ما نستبعدها نهائيًا، وفي الرسالة
بيتكتب بصراحة وقفنًا فين (عدد الفحوصات + السبب).

**ولو النوع نفسه قلّ** (زي الثلاثي: أسماء 3 أحرف محجوزة فعليًا بالكامل)
البوت **يوسّع لوحده لحد الأنواع المجاورة** ويكتب جنب كل اسم نوعه الحقيقي،
مش بيقولك "مفيش". يعني لو طلبت `16 ثلاثي` وملاقيش غير3، هتاخد الباقي
بـ `شبه ثلاثي` مكتوب جنبه `(شبه ثلاثي)` — كلهم مؤكدين بفحصين.

**مانع الحظر:** لو منصة بترجّع إجابات مهملة (حظر مؤقت) 5 مرات ورا بعض،
البوت **يقفّها60 ثانية** ويكمل على التانية بدل ما يضيّع كل الفحوصات،
ولو الاتنين مقفولين بيستني بدل ما يحرق الوقت.

وبعد ما تخلص أي دفعة توليد/بحث، بيظهرلك أزرار تحت النتيجة:
**🎲 توليد مرة أخرى** (نفس النوع والعدد) • **🔁 نوع توليد تاني** • **🔬 بحث عميق بنفس النوع**.


## 🔬 البحث العميق إزاي بيشتغل

1. **يولّد دفعة كبيرة** (لحد48 يوزر) — حوالين الكلمة اللي تختارها، ولو
   مفيش نتيجة يوسع البحث بأسماء عشوائية تاني (موجة ثانية).
2. **يفحصهم دفعة دفعة** مع تهدئة تتكيف مع الموقع (لو حس بحظر بيبطّأ لوحده
   ويعود للسرعة لما يخف).
3. **يأكّد كل يوزر "متاح" مرتين**: أول فحص عادي، وبعد ثانيتين فحص تاني
   **من غير كاش** على صفحة جديدة. لو الاسم "اتخدر" يترمي من القائمة.
4. يعرضلك **المؤكد بس**، ويقف بدري بعد ما يلاقي الكفاية (6 يوزرات).

> يعني لو شايف ✅ في نتيجة البحث العميق — ده فحصين متتاليين قالوا
> "غير محجوز". ومع ذلك سجّل بسرعة وراجع بـ `/check` قبل ما تفوّت.

**ملاحظة سرعة:** البحث العميق بياخد دقيقتين تقريبًا عشان بيفحص
عدة عشرات من الصفحات. لو الكلمة الأساسية شائعة جدًا (زي `gamer`)
هتلاقي كل الصيغ حوالها محجوزة — جرّب كلمة أقل شيوعًا عشان النتيجة أحسن.

## إزاي بيشتغل الفحص؟

المنصتين مافيش عندهن API رسمي يقول "الاسم ده فاضي"، فالبوت بيعمل الآتي:

1. **متصفح حقيقي (Chrome/Edge بدون واجهة)** يفتح صفحة البروفايل:
   - **تيكتوك:** لو الصفحة اتحمّلت وفيها `"uniqueId":"<الاسم>"` → ❌ محجوز.
     ولو ظهرت رسالة "Couldn't find this account" → ✅ غير محجوز.
   - **انستا:** لو ظهر `og:description` أو `profilePage_` → ❌ محجوز،
     ولو ظهرت "Profile isn't available" → ✅ غير محجوز.
2. لو المتصفح مش متاح أو اتحظر → **بدائل HTTP** (فحص الصفحة مباشرة،
   وفي تيكتوك كمان بحث في DuckDuckGo يثبت إن الاسم محجوز).
3. **كاش داخلي:** النتيجة بتتخزن6 ساعات (والنتيجة غير المؤكدة دقيقة واحدة فقط).

ليه متصفح؟ لأن تيكتوك بتحط "تحدي JavaScript" (WAF) على كل الطلبات العادية،
واللي بيجي عن طريق fetch بيرجع صفحة حجب — الكلام ده اتأكدنا منه عمليًا.

## ملاحظات وحدود

- ⚠️ الفحص **تقديري**. النتايج المتأكد منها (✅/❌) مبنية على محتوى الصفحة الفعلي،
  بس لازم تتأكد بنفسك قبل ما تحجز اليوزر.
- المنصتين بيحدّوا الطلبات الكتير. لو شفت ⚠️ كتير، استنى دقايق.
- البوت بيفحص **بدون تسجيل دخول** (زي أي زائر)، وده أأمن من ناحية حسابك.
- استخدم البوت بذكاء: مبالغة الفحص ممكن تسبب حظر مؤقت لعنوان IP بتاعك.
